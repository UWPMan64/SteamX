# Contributing

1. Keep the Xbox client UI and service logic separated.
2. Do not commit credentials, Steam API keys, refresh tokens, personal data, or game files.
3. Keep dependencies minimal; explain every new package.
4. Test Store responses defensively because the Store search endpoint is undocumented.
5. Include a short test plan with each pull request.
6. Never claim a feature works on Xbox until it has been tested on the target Xbox/UWP environment.
